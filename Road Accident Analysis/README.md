# Road Accident Analysis using Power BI

This project presents a data visualization dashboard analyzing road accident trends using **Power BI**. It provides insights into accident counts, causes, affected age groups, time trends, and more to help understand and reduce road-related incidents.

## 📊 Dashboard Features

- Total number of accidents
- Accident distribution by:
  - State/Region
  - Age group and gender
  - Vehicle type
- Key causes of accidents
- Year-wise and month-wise trends
- Fatal vs non-fatal incidents


## 📂 Files Included

- `Road_Accident_Analysis.pbix` — The main Power BI report file
- `Screenshots/` — Images of the dashboard for quick view

## 🧰 Tools Used

- Power BI Desktop
- Microsoft Excel/CSV
- Data cleaning & transformation using Power Query

## 📝 How to Use

1. Download or clone this repository.
2. Open the `.pbix` file using **Power BI Desktop**.
3. Make sure the dataset path is correctly mapped, or update it via Power BI’s data source settings.
4. Explore and interact with the dashboard!

## 📌 Notes

- The data used is for learning and demonstration purposes.
- You can replace the dataset with your local or national accident data to extend the analysis.
